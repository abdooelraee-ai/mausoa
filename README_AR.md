# موسوعة عبدالنور جابر — مشروع Android APK

هذا المشروع يغلف نسخة الويب المرفقة داخل تطبيق Android باستخدام WebView. محتوى الموسوعة محلي داخل التطبيق، لذا تعمل الواجهة دون استضافة موقع. البحث وفتح المصادر الخارجية يحتاجان اتصالًا بالإنترنت.

## بناء APK عبر GitHub Actions
1. ارفع محتويات هذا المجلد إلى مستودع GitHub جديد أو إلى المستودع الحالي.
2. تأكد أن الفرع اسمه `main` أو `master`.
3. افتح تبويب **Actions** في GitHub.
4. اختر **Build Android APK** ثم **Run workflow**، أو ادفع commit جديدًا.
5. بعد انتهاء البناء بنجاح، افتح عملية التشغيل (workflow run) ثم نزّل artifact باسم `mausoa-abdelnour-apk`.
6. فك ضغط الملف المنزّل؛ ستجد `app-debug.apk` لتثبيته على جهاز Android.

## ملاحظات
- هذا APK تجريبي (debug) مناسب للتثبيت والاختبار، وليس نسخة إصدار موقعة بمفتاح نشر خاص.
- للنشر على Google Play، يلزم إعداد توقيع release آمن وإنشاء AAB وفق متطلبات المتجر.
- لا يمكن بناء APK مباشرة في بيئة العمل الحالية لعدم توفر Android SDK/Gradle محليًا؛ GitHub Actions يوفر بيئة البناء.
